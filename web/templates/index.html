COMECE POR AQUI

Sua primeira conexão, passo a passo.

Do cadastro à rotação. Tudo o que você precisa para começar.

GUIA RÁPIDO / 04 PASSOS
01

Cadastre e identifique

Use Adicionar proxy. Dê um nome, escolha o protocolo e informe host e porta fornecidos pelo seu provedor. Preencha usuário e senha apenas se forem necessários.

Os endereços example.com são exemplos. Substitua por proxies reais.

02

Verifique a conexão

Clique em Verificar proxies. “Não verificada” significa que ainda não houve teste. O IP de saída aparece após a validação. Proxies indisponíveis podem ser testadas novamente.

O painel conectado não significa que todas as proxies funcionam.

03

Conecte seu aplicativo

Nas configurações de proxy do navegador ou aplicativo, use o endereço HTTP ou SOCKS5 exibido no topo. Mantenha o ProxsR em execução.

Você também pode baixar o PAC no topo. Ele permite conexão direta como alternativa se os proxies falharem.

04

Acompanhe a rotação

Os círculos mostram nome, ID, protocolo e uso de cada proxy. Na estratégia Ciclo, o anel avança a cada requisição até o limite definido. Próxima prepara outra proxy para a próxima requisição.

Uma conexão HTTPS aberta mantém a mesma proxy até encerrar.

O que significam os círculos?

O círculo branco identifica a última proxy selecionada. O anel representa o uso no ciclo, e o texto informa se ela está aguardando, não verificada, indisponível ou desativada. A identificação continua visível mesmo quando a proxy sai da rotação. Clique no círculo para editar.

Qual estratégia de rotação escolher?

Ciclo mantém cada proxy pelo número de requisições configurado. Sequencial alterna a cada seleção. Aleatória sorteia uma proxy disponível. Menos usada prioriza a proxy com menos requisições registradas. Nestas duas últimas, a próxima proxy não é previsível. Proxies fixas são usadas quando não há rotativas disponíveis.

Como editar, desativar ou remover uma proxy?

Use os botões da lista ou clique em um círculo. Editar mantém o ID; senha em branco mantém a senha anterior. Desativar preserva o cadastro. Excluir remove o cadastro após confirmação. A busca aceita nome, ID, host e IP.

O que fazer quando uma conexão falha?

Confira host, porta, protocolo e credenciais do provedor. Execute a verificação novamente. Se o painel informar perda de conexão, confirme que o ProxsR está em execução. Alterações nas portas exigem reiniciar o programa; ajustes de rotação são aplicados imediatamente.

O botão Sistema configura todos os aplicativos?

No GNOME ou KDE, ele altera as preferências de proxy do ambiente. Outros aplicativos podem ter configurações próprias. Em outros ambientes, o ProxsR prepara um arquivo de variáveis: execute source ~/.proxsr_env no terminal desejado. Isso não altera aplicativos já abertos.
